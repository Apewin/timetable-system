- 复现：导入后将“高一 AP 微观经济学”从 60 分钟改为 65 分钟；输入框失焦后仍显示 65；保存配置并完成求解。

- 影响：可能依据错误时长排考试、计算结束时间和休息，并产生错误 Excel；属于核心业务数据静默丢失。
- 备注：本轮使用受支持的 Playwright `fill + Tab` 真实页面交互。仍建议用人工键盘再复现一次；若人工键盘无法复现，可把问题收窄为自动化/辅助输入事件兼容缺陷，但在完成判定前不能放行。

### P2-01：第 3 阶段对学生冲突的 UI 与 API 证据矛盾

- UI：`校验通过：12 门考试无学生冲突`。
- API 警告：`当前为时间表阶段：未校验考生人数、学生冲突、考场和教师任务`。
- 影响：工作人员可能误认为学生名单级冲突已经独立校验；审核证据不一致。
- 建议：第 3 阶段明确写“按年级时间线无重叠，学生名单冲突将在第 4 阶段校验”，或让后端在第 3 阶段执行同等学生冲突校验。

### P3-01：运行门禁持续出现 Node `url.parse()` 弃用警告

- 影响：目前不阻断功能，但涉及安全语义弃用，建议迁移到 WHATWG `URL` API 并清理依赖来源。
