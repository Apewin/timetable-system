## 商用放行门槛

1. 不存在未关闭的 P0 或 P1 缺陷。
2. 所有关键业务 happy path 均有自动化或实际浏览器证据，且关键错误路径能够阻止错误写入并给出可操作反馈。
3. `pnpm install --frozen-lockfile`、`pnpm check`、完整 Chromium E2E、Ubuntu 原生求解测试全部通过。
4. 学生冲突、教师冲突、金框锁定、教师课时上限、考试日期/休息/座次/教师任务等硬约束均有独立校验证据。
5. 导入预览不写状态；确认导入有版本与校验保护；课表、考试、教师任务和座次工作簿可打开、可打印、内容可追溯。
6. 计算任务具备进度、取消、超时、失败隔离和刷新恢复；不得因求解失败覆盖最近有效结果。
7. 生产仅通过 HTTPS 反向代理访问；应用只监听本机；状态、审计、备份与发布目录权限符合单校受信任管理员部署边界。
8. 发布前备份、原子切换、健康检查与旧版本回滚材料均可验证。

## 缺陷等级

- P0：数据丢失、越权泄露、系统不可启动或核心流程完全不可用。
- P1：核心业务生成错误、硬约束被破坏、导入导出不可用、无法安全恢复。
- P2：存在可靠绕行方式但会明显增加误操作、人工复核或运维风险。
- P3：文案、布局、可访问性或低概率边界问题，不影响核心结果正确性。
